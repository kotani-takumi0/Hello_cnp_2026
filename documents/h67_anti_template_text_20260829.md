# H67: 業界条件付き「反定型文」前処理

## 結論

- **E3差し替えは弱いACCEPT（候補保存、まだ本番昇格はしない）**。
  strict 5反復で baseline 比 `ΔAUC +0.00019 / ΔAP +0.00085 / ΔF1 ±0.00000`。
  AUC/AP は4/5 seedで正、F1は全seedで完全同値だった。
- **9本目追加はREJECT**。`ΔAP +0.00212` は出たが、1 seedの閾値越境により
  `ΔF1 -0.00256` となり、既定のF1ガードレール `-0.002` を割った。
- 反定型文単体は原文E3に明確に負けた。これは「強い新表現」ではなく、原文の約78%
  を捨てることで生じた弱い正則化・多様化としてのみ効いている。

したがって、現行8本を直ちに変更しない。差し替え案だけを次段のfresh 15 seed候補として
残し、次のテキスト試作ではハード削除ではなく定型度を連続値として使う。

## 仮説

`今後のDX展望` は1社あたり中央値12文と長く、「今後もDXを推進する」など同業他社にも
共通する定型文がTF-IDFを薄めている可能性がある。購入ラベルで重要文を選ぶのではなく、
同業他社の文体重心から遠い文を「その会社固有の文」とみなし、そこだけを既存E3へ渡す。

## 事前固定した前処理

1. `。！？!?` と改行で文分割し、12文字未満の断片を落とす。
2. fitting fold内の全文だけで sentence-level char TF-IDF をfitする。
   - `analyzer=char_wb`
   - `ngram_range=(2, 4)`
   - `min_df=3`
   - `sublinear_tf=True`, L2正規化
3. 各業界の文ベクトル重心を作り、100文相当のglobal重心へ縮小する。
4. 各文の `1 - cosine(sentence, shrunk industry centroid)` を固有度とする。
5. 固有度上位3文だけを選び、元の出現順へ戻して連結する。
6. 選択後は既存E3と同一の char TF-IDF + LR を使う。分類器の設定は変えない。

学習文書を選別するときは、その会社の全文章をglobal重心と業界重心の双方から除外した。
これにより自分の文が自分自身を定型側へ引く非対称性を避けた。validation/holdout文書は重心・
語彙・IDFのいずれにも入らない。

## リーク・再現性検査

- target側20件のラベルを全反転して再予測: 最大確率差 `0.0`
- 同一入力の再実行: 最大確率差 `0.0`
- 出力確率: 全件finite
- strict outer holdout: Bラベルは最終採点以外で不使用
- 既存8 expertの予測はbaseline/差し替え/追加で同じ配列を共有
- 選択後の文字数は原文の約22.2%

## 1. テキスト単体OOF

5-fold OOFをseed 670--674で反復した。閾値を介さないAUC/APだけで表現自体を比較した。

| model | AUC mean±std | AP mean±std | 原文E3とのSpearman |
|---|---:|---:|---:|
| 原文E3 | 0.78696 ± 0.00142 | 0.51469 ± 0.00624 | 1.00000 |
| 反定型文 | 0.74960 ± 0.01030 | 0.46794 ± 0.01716 | 0.85912 |
| 差分 | **-0.03736 (0/5勝)** | **-0.04675 (0/5勝)** | - |

固有度上位3文だけでは購入意向に効く共通表現まで落ちた。長文中の定型的な推進語にも、
ラベルに関する実信号が含まれている。

## 2. strict outer holdout

- outer A/B: stratified、B=35%、seed 600--604
- A内5-fold OOFだけでexpert/meta学習とalpha選択
- 閾値: Aだけから決める `half_f1`
- 比較:
  - 現行8本
  - E3を反定型文へ差し替えた8本
  - 現行8本へ反定型文を加えた9本

| config | AUC | AP | F1 | ΔAUC | ΔAP | ΔF1 |
|---|---:|---:|---:|---:|---:|---:|
| 現行8本 | 0.95694 | 0.88343 | 0.77485 | - | - | - |
| E3差し替え | 0.95713 | 0.88428 | 0.77485 | **+0.00019 (4/5)** | **+0.00085 (4/5)** | **±0.00000 (全てtie)** |
| 9本目追加 | 0.95788 | 0.88555 | 0.77229 | +0.00093 (3/5) | +0.00212 (4/5) | **-0.00256** |
| 反定型文単体 | 0.75523 | 0.49198 | 0.53489 | - | - | - |

baselineの `0.1 < p < 0.9` 曖昧帯でも、差し替えは
`ΔAUC +0.00039 / ΔAP +0.00091`、追加は
`ΔAUC +0.00223 / ΔAP +0.00196` だった。

平均meta重みは次の通り。

| config | 原文E3 | 反定型文 |
|---|---:|---:|
| 現行8本 | 0.01926 | - |
| E3差し替え | - | 0.01228 |
| 9本目追加 | 0.01274 | 0.00941 |

反定型文と既存expertの最大絶対Spearmanはseed別に0.815--0.850。完全な重複ではないが、
単体損失を補えるほど強くもない。追加時にはメタ自由度と閾値付近の微小な順位変化が
F1を1 seedだけ悪化させた。

## 判定と次の試作

既定の `decision.verdict` では差し替えが **ACCEPT（弱い）**、追加が
**REJECT（F1ガードレール違反）**。ただし差し替えの平均AP差は明確採用基準
`+0.005` より一桁小さく、単体性能も悪いため、productionへはまだ入れない。

次のH68候補は **soft anti-template residual**。文を捨てず、原文TF-IDFを残したまま
各文の定型度を連続重みに変換する。具体的には、各文のn-gram値を
`0.5 + 0.5 × novelty` で再重み付けし、共通信号を最低50%残す。H67の「多様化はわずかに
効くが、ハード削除で信号を落としすぎた」という観測を直接反映した一手にする。
