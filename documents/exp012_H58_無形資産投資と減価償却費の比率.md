## 仮説

無形固定資産投資額が、減価償却費（既存資産の自然な目減り分）を上回っている企業は、単に資産を維持するだけでなく積極的にデジタル資産を積み増している成長企業であり、DX教育投資にも積極的なのではないか。

一般論のみで設計（購入率は一切参照していない）。財務理論において、投資額が減価償却費を上回る状態は、資産の「純増」を意味する一般的な指標。

---

## 実装

```python
def h58_intangible_vs_depreciation(train, X):
    X = X.copy()
    intangible = train["無形固定資産変動(ソフトウェア関連)"].abs()
    depreciation = train["減価償却費"].abs()
    X["無形投資_減価償却比"] = _safe_div(intangible, depreciation + 1)
    return X
```
