# H68: soft anti-template residual

## 結論

**REJECT。現行E3は変更しない。**

- テキスト単体: 原文E3比 `ΔAUC -0.00529 / ΔAP -0.01277`、ともに0/5勝。
- strict E3差し替え: `ΔAUC -0.00002 / ΔAP -0.00001 / ΔF1 ±0.00000`。
- strict 9本目追加: `ΔAUC -0.00029 / ΔAP -0.00050 / ΔF1 ±0.00000`。
- 原文E3とのOOF Spearmanは0.993前後。ハード抽出H67より信号損失は減ったが、
  独立情報もほぼ消えた。

床値を結果後に0.7や0.8へ調整する探索は行わない。相関がさらに1へ近づくだけで、H68の
「原文を残しながら固有文を強調する」という仮説に支持がなかったためである。

## 前処理

H67と同じtarget-freeな業界条件付き文固有度を使う。

1. fitting fold内の文だけでchar TF-IDF空間を作る。
2. 業界別重心をglobal重心100文相当へ縮小する。
3. 学習文書はleave-one-company-outで重心から除外する。
4. 各文の重心からのcosine距離を、文書内percentile rank `[0, 1]` へ変換する。
5. 各文のn-gramカウントを次式で重み付けする。

   `weight = 0.5 + 0.5 × relative_novelty`

6. 全文のカウントを最低50%残し、固有度分だけ残り50%を加える。短い断片や文境界をまたぐ
   n-gramも50%は必ず残る。
7. 重み付きfractional countを集約してから、現行E3と同じsublinear TF、training-fold IDF、
   L2正規化、`C=1.0` LRを適用する。

平均文重みは設計どおり0.750、最小0.500、最大1.000。

## 実装対照・リーク検査

- `base_weight=1.0` と現行E3の最大確率差: `2.22e-16`
- target側ラベルを全反転した最大確率差: `0.0`
- 同一入力の再実行差: `0.0`
- sparse特徴・予測確率: 全件finite
- selector語彙、IDF、業界重心、LRはすべてfitting fold内だけでfit
- strict比較では既存8 expertの予測配列を3構成で共有

したがって、H68の差は語彙・IDF・分類器・正則化変更ではなく、文重みだけに帰属できる。

## 解釈

H67は文を約22%まで削ることでSpearman約0.84の別ビューになり、差し替えで微小なAP改善が
出た。一方H68は全文を保持したためSpearman約0.993となり、元E3とほぼ同じ弱いコピーに
なった。つまり今回の設計では、次の二つを同時に満たせなかった。

- 共通文に含まれる購入意向信号を保持する
- metaに有用な独立残差を作る

次に進めるなら床値グリッドではなく、H67と原文E3の予測差をtraining fold内で明示的に
直交化する **H69 contrastive residual expert** が筋がよい。非負metaがそのままでは使えない
`hard anti-template - full E3` の符号付き残差だけをcross-fitし、追加情報が本当にあるかを
直接検定する。
