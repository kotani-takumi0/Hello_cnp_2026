# H89 曖昧帯に、この特徴空間の取り残しはあるか — 2026-08-30

「2段目にどんな情報を足すか」を考える前に、**そもそも今の列に取り残しがあるのか**を
測った。モデルを介さない局所的なテストなので、どのモデル族の帰納バイアスも入らない。

各行について、**自分以外の最近傍がラベルを共有する割合**を見る。

- 帯の中で近傍がラベルを共有しないなら、**似ている企業が違う判断をしている**＝
  この列では分離できず、どんな合成器も2段目も効かない
- 共有するなら、大域モデルが均してしまった局所構造があり、局所手法に価値がある

再現:

```bash
.venv/bin/python exp/diagnose_band_local_structure.py
```

---

## 1. 帰無値の取り方（最初に間違えた）

近傍は全742行から引かれるので、帰無値は**全体の購入率 0.2412** で決まる。
ラベル `y_i` の行に対し、ランダムな近傍が一致する確率は
`y_i·r + (1-y_i)·(1-r)`。

初版では領域内の購入率で帰無値を計算してしまい、確信帯が「偶然以下」という
無意味な値になった。訂正済み。あわせて「近傍を領域の中だけから探す版」も出した
（こちらの帰無値は領域内の購入率でよい）。

## 2. 結果（seed 42、帯212行、実購入率 0.4528）

**合成の帯内AUC は 0.8242** —— モデルは帯の中でも十分に効いている。
問題は、そこに*局所*構造が残っているかどうかである。

## 3. 読み方

**確信-購入の行は、表形式空間で近傍が +0.314 もラベルを共有する。**
つまりこの特徴空間はラベルを強く符号化している。空間が悪いのではない。

**その同じ空間で、曖昧帯の行は近傍から何も分からない（超過 ±0.03 以内）。**

そして合成の帯内AUC は 0.8242 と高い。整理すると：

- モデルは帯の中でも**大域的な**順序付けから多くを取り出している（AUC 0.824）
- しかし帯の中に**局所的な**構造は無い（近傍一致率が偶然と同じ）
- 2段目のモデルは必然的に特徴空間の構造に依存するので、**使える材料が無い**

これが H86（帯専門モデル）が負けた理由の実体である。あの λ選択が
55 fold中39回で「使う」を選んだのは、160行で測る帯内APの標準誤差 0.04〜0.05 の
中で偶然の正を拾っていたからで、拾うべき構造は最初から無かった。

## 4. 「2段目に何を足すか」への答え

**この4つの空間（表形式・企業概要・組織図・DX展望）の外にある情報。**

曖昧帯の企業は、今ある列で見る限り互いに区別がつかない。似た規模・似た業界・
似た財務・似たテキスト・アンケートは全部3 —— それでいて片方は買い、片方は買わない。
`uncertain_band_profile_20260828.md` が「あらゆる軸の真ん中」と表現した通りである。

業務的に言えば、残差を説明しそうなのは**予算サイクル・社内の推進者の有無・
競合の導入状況・過去の商談履歴**といったもので、いずれも配布データに無い。

### したがって

- 合成の仕方（H72/H73/H85/H86/H87/H88 の254通り＋各種ゲート）はもう探索し尽くした
- 特徴量の作り方も、この4空間の中では [[dx_text_is_one_dimension]] を含め尽くされている
- **精度で前に出るには、データセットに無い情報が要る**

## 5. 「不足している情報を作る」ことはできるか

### 5.1 見分けのつかない反対ラベルのペアが951組ある

財務・規模・アンケートを含む75列の標準化空間で、曖昧帯212行のペアを調べた。

```
同ラベルのペア 類似度中央値  -0.0135
異ラベルのペア 類似度中央値  -0.0125
差 -0.0010   ← 似ていることがラベルの手がかりに全くならない
```

さらに「特徴が似ていて・**モデルのpも0.05以内**・ラベルが逆」のペアが**951組**ある。

```
類似度 0.8240  p差 0.010
  ID 554  購入=0  p=0.751  従業員1619  コンサル PR BtoB  アンケート(1,4,7,8,10)=[2,4,4,5,3]
  ID 491  購入=1  p=0.741  従業員 858  IT      PR BtoB  アンケート(1,4,7,8,10)=[1,5,4,3,5]

類似度 0.7662  p差 0.008
  ID 676  購入=0  p=0.105  従業員 611  IT PR BtoB       アンケート=[2,3,NaN,1,1]
  ID 693  購入=1  p=0.112  従業員 611  IT ST BtoB,BtoC  アンケート=[3,2,1,3,5]
```

**212行の帯の中に951組。これは例外ではなく帯の構造そのものである。**

> 注: 数値列だけの空間で最初に探したときの最類似ペア（ID 187 / 527、類似度0.8848）は
> **モデルが正しく区別できていた**（アンケート8が4対1、p が 0.117 対 0.555）。
> 類似度空間にアンケートを入れていなかったための見かけの矛盾。上表は入れ直した版。

### 5.2 したがって

| 案 | 判定 | 理由 |
|---|---|---|
| 外部の実データを引く | **不可能** | 企業は架空。企業名に対応する実体が無い |
| LLMで特徴を生成する | **情報は増えない** | LLM特徴は `g(テキスト, 表形式)` の決定的な関数。
`x` の関数は、`x` が同じ行を分離できない。上の951組がまさにそれ |
| 合成データで水増し | 無意味 | 実ラベルについての情報が増えない |

**関数は、入力が同じ行を区別できない。** これが「作る」ことの限界である。

### 5.3 唯一の留保

「入力が同じ」とは「ここで測った空間で同じ」の意味である。全文を読むLLMが
埋め込みの平均化で失われる構成的な情報を拾う可能性は、原理的には残る。ただし:

- 帯でのブラインド試行（n=40）は逆向き ── LLM 20/40 に対しモデル 25/40
  （McNemar p=0.36 で検出力は不足しており、決定的ではない）
- DX展望埋め込みの帯内局所構造は ±0.03 以内（§2）
- それを動機づけた「すでに充足している企業は買わない」という非単調構造は
  **データに見えない** ── PC1五分位の購入率は 53.0→36.5→16.9→7.4→6.7% と単調
  （[[dx_text_is_one_dimension]]）

### 5.4 これは負けではなく、発表の中身になる

**「測定可能なあらゆる軸で見分けがつかない企業が、逆の判断をしている」**
——これは業務的な結論そのものである。購買を決めているのは配布データに無いもの
（予算サイクル・社内の推進者・競合の導入状況・商談履歴）であり、
**スコアリングだけでは到達できない層が239社いる**という話になる。
施策としては「この層はスコアで刈るのではなく、接触して聞くしかない」に落ちる。
