# H97 ノイズ整合スタッキング — ランキングは良くなるが、閾値則に飲まれる — 2026-09-01

## 結論

**REJECT（事前登録した `exp/decision.py` 既定による）。提出物は変更しない。**

ただし中身は「効かない」ではなく **「+0.008 の利得が ±0.05 の閾値ノイズに埋もれた」**。
副産物として、**本番のボトルネックはランキングではなく閾値則**であることが定量化された。

再現:

```bash
OMP_NUM_THREADS=4 .venv/bin/python exp/compare_noise_matched_stacking.py --n-reps 11 --n-seeds 5
```

## 1. 何を直そうとしたか

本番ではメタの入力が学習時とtest時で別物になっている。

- エキスパートのOOF予測 = **1モデル/行**
- エキスパートのtest予測 = **5fold平均**（`ensemble_experts.py` の `te[name]`）

同じ列のseed間sd(logit)の OOF/test 比:

| Expert | OOF | test | 比 |
|---|---:|---:|---:|
| E0_anchor | 0.774 | 0.212 | 3.7x |
| E1_finance | 0.503 | 0.128 | 3.9x |
| E6_manual | 0.363 | 0.093 | 3.9x |
| E0b_linear | 0.308 | 0.047 | 6.6x |
| E7_cross | 0.153 | 0.010 | 16x |
| E3_dx_text | 0.051 | 0.002 | 22x |
| E2_survey | 0.145 | 0.006 | 24x |
| E4_org_text | 0.082 | 0.003 | 30x |

メタは**ノイズの多い入力で学習してノイズの少ない入力に適用**している。errors-in-variables で
係数が減衰し、減衰量が列ごとに違うので重み配分自体が歪む。

候補は **A の中で S seed 分 cross-fitting を繰り返し、OOF も B予測も同じ S seed で平均してから
メタを張る**（repeated cross-fitting）。両側のノイズ水準が揃う。

### 既存ハーネスは使えない

`holdout_check.one_rep` は B側を **A全体で1回学習した単一モデル**で予測しており、本番（5fold平均）の
ノイズ構造を再現していない。本実験は baseline 側も5fold平均で B を予測する＝本番と同じにした。
baseline は候補の j=0 成分そのもの（A/B分割・fold分割・alpha選択まで共有）＝入れ子のペア比較。

### 2.2 判定

`exp/decision.py` の既定（n=11 なら ΔAUC正 8/11、ΔAP正 9/11、平均ΔF1 ≥ -0.002）に対し、
**ΔAUC 7/11、ΔAP 7/11 で検出ゲートを通らない** → `REJECT (ノイズと区別できず)`。

AUC/AP は実損4repを含むので、タイの数え方の問題ではない。**大域ランキングの改善は
検出限界以下**というのが正しい読み。

## 3. なぜ F1@k固定 だけ一方向なのか

k を揃えると **11rep中1度も負けない**（5勝6分0敗、非タイ5本が全部同符号なので符号検定は
p=0.062 ＝この標本数での下限）。一方 AUC/AP は 7/11。

top-k の入替は **平均1.8行/rep**（k≈73）。ΔF1 +0.0082 は正例1件あたり 2/136 = 0.0147 なので
**約0.56 TP/rep** に相当する。つまり効果は**閾値近傍の数行だけ**に出ており、
全順位を積分する AUC/AP では薄まる。曖昧帯（|p-0.5| が小さく行間のギャップが小さい領域）で
推定分散の削減が最も効く、という機構と整合する。

タイが6repあるのは自然で、入替が起きても FP↔FP の交換なら F1 は動かない。

## 4. 本当の発見 — 閾値則のノイズがランキング利得の6倍ある

| 由来 | 大きさ |
|---|---:|
| ノイズ整合によるランキング改善 | **+0.008** |
| `oof_best` 閾値選択のrep間ばらつき | **±0.05** |

自前閾値のF1は 5勝0分6敗・最悪 -0.0499 で、ランキングが改善しているのに符号が定まらない。
A側で選ばれた閾値そのものが rep間で大きく振れている:

```
baseline の閾値: 0.285 – 0.475（幅 0.19）
候補の閾値    : 0.320 – 0.415（幅 0.095）
```

平均化は閾値の**幅を半分に狭めた**が、それでも F1 への影響はランキング利得を飲み込む。
これは `f1_at_auto_threshold_is_not_comparable`（近最適帯が幅0.095で argmax がノイズ）の
直接的な再確認であり、**11repでは閾値ノイズ越しにランキング利得を検出できない**ことを意味する。

### 4.1 含意

96仮説はすべて「ランキングを良くする」方向だった。しかし**出荷時の分散の主項は閾値**である。
ここで思い出すべき既存資産:

- `cbpe_platt` 閾値則は 20rep で **+0.0122・分散46-77%減**。本番切替が保留されている理由は
  Public 0.8095→0.7627 の**1ドロー**のみ（8行変更）。これは exp036 が5seed平均を落としたのと
  同じ「Public差0.03未満を判断に使わない」則違反である。

**施策1単体は PARK が妥当だが、`cbpe_platt` と組めば話が変わる可能性がある** ——
施策1がランキングを、`cbpe_platt` が閾値を、それぞれ別の分散源に効くため。

## 5. 2x2（閾値則 × S）— 実施済み

同じ11repの土台で3則を測った。B側の絶対値（rep平均）:

| 閾値則 | S=1 | S=3 | S=5 | 最悪rep (S=1 / S=3) |
|---|---:|---:|---:|---|
| oof_best | 0.8152 | 0.8157 | 0.8185 | 0.7671 / 0.7564 |
| half_f1（現本番） | 0.8213 | 0.8268 | 0.8267 | 0.7903 / 0.7907 |
| **cbpe_platt** | **0.8243** | **0.8294** | 0.8275 | 0.7903 / **0.7969** |

- **Q1: `cbpe_platt` は `oof_best` に勝つ。** Δ+0.0091、勝7分1負3、rep間sd 0.0240→0.0204、
  最悪rep 0.7671→0.7903。事前登録した基準（平均>0・負≤3・sd増えず）を全て満たす。
- **`oof_best` は3則で最下位。** 現本番が `half_f1` を使っているのは正しい。
- Q2: ノイズ整合の利得は良い閾値則の下でも残るが弱い（cbpe_platt下で S=3 +0.0051）。

## 6. ただし、ここが本題 — 追っている効果が分解能より小さい

| 比較 | Δ平均 | ペアSE | Δ/SE | 勝/分/負 |
|---|---:|---:|---:|---:|
| cbpe_platt vs oof_best | +0.0091 | 0.0061 | 1.49 | 7/1/3 |
| half_f1 vs oof_best | +0.0061 | 0.0063 | **0.96** | 6/1/4 |
| S=3 vs S=1 (cbpe_platt) | +0.0051 | 0.0042 | 1.20 | 4/5/2 |
| **S=5 vs S=3** | **-0.0019** | 0.0033 | **-0.57** | 4/3/4 |
| cbpe_platt vs half_f1 | +0.0030 | 0.0018 | 1.71 | 3/8/0 |
| 最良セル vs 現本番 | +0.0081 | 0.0036 | **2.24** | **6/5/0** |

**11repホールドアウトの分解能は ±0.0125（2SE）、Public 1ドローは ±0.0864（2SD）。**
2σを超えたのは合成した最後の1行だけで、個別判断はほぼ全部が検出限界以下である。
「S=3が最良」も -0.57σ ＝ **平らな曲線のargmaxを拾っただけ**で、S=3とS=5に差は無い。

### 6.1 自分のローカル推定にも勝者の呪いがかかっている

**96個の仮説を、すべて同じ742行の分割で評価してきた。** 各ホールドアウトが個別に正直でも、
約100個のノイズ推定の最大値を選べばその最大値は上振れる。SE≈0.006・100構成なら
E[max] ≈ 2.5×0.006 ≈ **+0.015**。ローカルの 0.8213 は真値では **0.806 前後**の可能性が高い。

これは `bayes_ceiling_and_new_angles` で「LB 0.88 は、トップが真値0.83である場合と完全に整合する」
と書いた論理とまったく同じである。**他人のLBには適用したのに、自分のローカル推定には
適用していなかった。** 同じ補正を今日の +0.0081 にかけると（12セルの最大＝1.6×0.0036）、
差し引き **+0.002 程度**しか残らない。

### 6.2 Public との乖離は構造的欠陥ではない

B側の実データから240行1ドローのF1分布を作ると **sd = 0.0432**（実測のPublic SD 0.043 と一致）。
提出した `slot1` の Public 0.7826 はこの分布の **下側18.3%点**で、真値0.82と整合する。
11repのB側F1（最小0.7903）を全部下回るのは、repどうしが同じ742行を共有していて
散らばりを過小評価しているため。分割の偏りも無い（Public実正例 A=59 は基準率から期待される57.9と一致、
各提出のPublic予測正例数も期待0.30Nに対し z=-0.92〜+0.03）。

### 6.3 したがって

残り headroom（曖昧帯の構造から来る上限 ~0.83 と現在地 ~0.81 の差）が、**それを測る能力より小さい**。
この状態で実験を追加すると、得られる利得より蓄積する選択バイアスのほうが大きい。**探索は止める。**

実質的なレバーは**最終2枠の選び方**だけ。しかも「ローカル最良を2つ」は誤りで、上位構成が団子である以上、
**最大値を取れるルールを活かして相関の低い2つを選ぶ**のが正しい。
