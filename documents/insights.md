# 示唆の整理 — DX教育商材 購入予測

目的: 特徴量を一度に足さず **1仮説ずつ** 検証する。そのために示唆を信頼性で分類する。

## 分類の定義

| 区分 | 意味 | Private耐性 | 扱い |
|------|------|-------------|------|
| **A. 両方** | データでも観測 かつ 一般論でも支持 | 高い | 最優先で特徴量化 |
| **B. データのみ** | データでは見えるが一般論の裏付け弱い/逆行 | 低い（過学習リスク） | CVで慎重に検証、解釈できるか確認してから採用 |
| **C. 一般論のみ** | 一般論では言われるがデータで未確認/弱い | 中（汎化はしうる） | 代理変数で検証。効けば強い |

> 前提: train 742行 / 正例率 24.1% / Public は評価データの30%のみ → **OOF(CV) を信頼**し Public過学習を避ける。

---

## A. 両方で支持される示唆（最優先）

### A1. 収益性が高いほど購入
- **データ**: 営業利益率(営業利益/売上) 4分位で単調 Q1=12.6% → Q4=**40.0%**。当期純利益 corr_log +0.21、営業CF +0.21、営業利益 +0.19。
- **一般論**: 教育商材は裁量的支出。利益・キャッシュ余力のある企業が投資できる。
- **未特徴量化**: baselineは生の財務額のみ。利益率(=規模で正規化)は未投入。

### A2. 企業規模が大きいほど購入
- **データ**: 従業員数 4分位で単調 Q1=14.0% → Q4=29.6%。総資産/自己資本/純資産も corr_log +0.12〜0.15。
- **一般論**: 研修対象人数が多く、予算・専任HR部門を持つ。

### A3. ソフトウェア投資額が大きいほど購入
- **データ**: 無形固定資産変動(ソフト)は **全742件が負値＝投資アウトフロー**。絶対額が大きいほど購入。corr_log -0.23（baselineで**最重要**特徴）。
- **一般論**: デジタル投資に積極的な企業は人材育成にも投資する（DXの車の両輪）。
- ⚠ 単独依存はPrivateで危険 → 他の財務比率で補強したい（B4参照）。

### A4. 業界差（知識集約 > 現場労働）
- **データ**: 高=IT46.8% / 人材50% / 自動車44.9% / 金融33% / コンサル33%。低=外食5% / 小売7.3% / 食品8% / 建設9.1% / 運輸8%。
- **一般論**: ホワイトカラー比率・デジタルスキル需要の高い業界ほど投資必要性が大きい。

### A5. BtoB > BtoC
- **データ**: BtoB 27.4% / BtoB,BtoC 23.6% / BtoC **6.5%**。
- **一般論**: BtoBは知識労働中心、BtoCは現場労働中心で研修対象が異なる。

### A6. DX戦略の明確さ
- **データ**: アンケート1(戦略の明確さ) corr +0.073（弱いが方向一致）。
- **一般論**: 戦略が明確な企業ほど実装フェーズ（＝教育）に進む。

### A7. 現状への不満・課題感が購買を駆動
- **データ**: アンケート7(既存ツール満足度) corr **-0.258**（最強の単一アンケート、導入済み386社内）。アンケート2(社内DX満足度) -0.09、アンケート4(変革抵抗感) -0.11。
- **一般論**: ニーズギャップ（現状不満）が購買行動を駆動する。満足していれば買わない。

### A8. 上場種別: 大市場 > 小市場
- **データ**: GR35.7% / PR28.4% / ST**11.5%**。
- **一般論**: 大企業・ガバナンス強度・人的資本開示圧力が投資を後押し。

## B. データのみ（過学習注意・要慎重検証）

### B1. アンケート10（外部パートナー連携実績）が低いほど購入
- データ: corr -0.158（2番目に強いアンケート）。
- ⚠ **一般論とはむしろ逆**（連携実績豊富＝ベンダー接点多く買いそう）。架空データ特有の可能性 → 採用は effect の安定性(fold間)を確認してから。

### B2. 投資CF・有形固定資産変動の負相関
- 投資CF corr -0.164 / 有形固定資産変動 -0.167（生）。A3(ソフト投資)と交絡の可能性 → 独立の寄与があるか要確認。

### B3. 少数カテゴリの極端な購入率
- 通信機器 n=1=100% / 通信 n=5=80% / 教育 n=6 / ゲーム n=4。**過学習の温床**。頻度エンコード or 統合カテゴリ化を検討。

### B4. baselineで無形固定資産変動が突出して重要
- gain 1167（2位の業界554の2倍）。単独依存はPrivateでスコア崩壊リスク → 他財務比率で分散させる。

## C. 一般論のみ（データ未確認 / 代理変数で検証）

### C1. 人的資本開示・ESG圧力
- 直接列なし → 上場種別(A8)・規模(A2)で代理済み。

### C2. 従業員1人あたり指標（デジタル密度）
- 売上/従業員(労働生産性)、ソフト投資/従業員、総資産/従業員 など。「高生産性 or デジタル密度が高い企業が買う」仮説。**データで未作成** → 作って検証する価値大。

### C3. 財務健全性（自己資本比率・負債比率）
- 健全な企業ほど投資余力。自己資本比率(自己資本/総資産) 等は未作成。A1(収益性)と別軸。

## 検証キュー（1仮説ずつ）

順序 = A（確実）→ C（伸びしろ）→ B（慎重）。各仮説は「OOF F1 が baseline 0.6667 を超えるか」で判定。

| # | 仮説 | 区分 | 追加特徴量 | スモーク(N=3) | 本判定(N=10+) |
|---|------|------|-----------|--------------|---------------|
| H1 | 収益性の正規化が効く | A1 | 利益率3本(営業/経常/純) | **PARK**(AUC3/3) | 要確認・最有力 |
| H2 | 財務健全性が効く | C3 | 自己資本比率, 負債比率, ROA, ROE | REJECT | — |
| H3 | デジタル密度が効く | C2 | ソフト投資/従業員, 売上/従業員, 総資産/従業員 | REJECT(F1単seed高) | **REJECT** (on H1・N=6で全指標3/6) |
| H4 | ニーズギャップの明示化 | A7 | 不満スコア, 戦略-満足ギャップ, 既存ツール不満 | REJECT(F1悪化) | — |
| H4b | ニーズギャップ忠実版 | A7 | DX意欲/実現/ギャップ, ツール不満 | — | **REJECT**(on H1・N=6, AUC3/6)。survey和は木が近似 |
| H5 | 業界の購入率エンコード | A4/B3 | target encoding(CV内fit) | **REJECT(有害)** | 棄却(TEは冗長) |
| H6 | アンケート10の符号安定性 | B1 | fold間で効果が安定か検証のみ | 未着手 | — |
| H7 | 現金ベースの投資余力(②) | A1別軸 | 営業CFマージン, FCF比率, 現金ROA | AP 5/6 | **REJECT**(CV N=15でバー未達→Public 0.5778で悪化確認。OOF AUC/APは過大評価だった) |

> **判定ルール（数値根拠つき）**: 同一seedでbaselineとペア比較（`exp/run_hypothesis.py`）。
> - 検出=ΔAUC正の割合≥70%、妥当性=ΔAP正の割合≥75%、ガードレール=平均ΔF1≥-0.002
> - 検出○&妥当性○→ACCEPT / 検出○&妥当性✕→PARK / 検出✕→REJECT
> - N=3はスモーク（配管確認）。最終判定は N=10〜15。
> - 実測ノイズ: baseline F1=0.66±0.013、**乱数特徴でも単seed F1は+0.013出る**→単seed F1では判定不可。
> - 全ログ: `exp/hypothesis_log.md`

## 検証で分かったこと（2026-08-03 時点）

### 結果サマリー
- **H1(利益率) だけ採用**。Public F1 0.6029→**0.6111 (+0.0082)**。H2/H3/H4/H5 は不採用。
- 現baseline = baseline + H1。以降の検証はこの上で行う（greedy forward）。

### 方法論の学び（最重要）
1. **単seedのOOF F1は判定に使えない**。実測: baseline F1=0.66±0.013、乱数特徴でも単seed F1は+0.013出る。
   実際 H1 は SEED=42 の OOF F1 では baseline を下回った(0.6569<0.6667)が **Publicは上がった**。
2. **AUC=検出 / AP=F1妥当性 / F1=ガードレール の3段判定が機能**。H1は「AUC○AP△＝PARK」だったが
   Publicで効いた → AUC改善（順位付け）はF1にも汎化しうる。検出はAUCで見るのが正解。
3. **ペア比較＋符号検定**なら少seedでも当たりが付く（H3が全指標きっかり3/6=綺麗なnull）。

### データ/モデルの学び
- **baseline（生の財務額＋LGBMネイティブカテゴリ）は既に強い**。木が分割で近似できる変換
  （比率・正規化・target encoding）は上乗せしにくい。H1以外全滅、H5(TE)はむしろ有害。
- H1が効いたのは、規模で割った収益性が生の額から1分割では作りにくいため、と解釈。
- **未開拓の空白＝テキスト**（`今後のDX展望`=購入意欲そのもの, `企業概要`）。数値・カテゴリ系は
  飽和気味 → 次の伸びしろはテキストの可能性が高い。

### 次の方針
- A/C由来の数値比率は期待値低下 → **テキスト特徴** or **H4作り直し**（不満スコアは方向◎だが合成が悪くF1↓）へ。
