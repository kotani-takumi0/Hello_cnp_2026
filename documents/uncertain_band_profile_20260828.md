# 曖昧帯のプロファイルと、ドメイン仮説25本の帯内スクリーニング — 2026-08-28

## 0. 結論

現本命が迷う228行（test側239行）の正体は **「中規模・BtoB・DX関連業界・ソフト投資も
中程度・アンケートは全部3」** という、あらゆる軸の真ん中にいる企業群である。

帯の中で購入/非購入を分ける生列は、41列中**アンケート８（DX成果の実感）ただ1本**しか
95%CIで有意にならない。方向は逆相関で、**成果を実感できていない企業ほど買う**。

ドメイン仮説から25本の特徴を作って帯内でスクリーニングしたところ、6本が95%CIで有意に
なった。**その6本すべてがQ8を含む。** しかし多重補正では全滅し、さらに決定的テスト
（現本命スコアの上に足して帯内AP/AUCが動くか）では**AP が下がった**。よって**採用しない**。

得られたのは特徴量ではなく**解釈**である。それはプレゼン審査に直接使える。

再現:

```bash
.venv/bin/python exp/profile_uncertain_band.py
.venv/bin/python exp/profile_uncertain_band.py --lo 0.15 --hi 0.85
```

## 4. ドメイン仮説25本の帯内スクリーニング

### 4.1 立てた仮説

「従業員向けDX教育商材を誰が買うか」を業務側から考え、既存42列から作れる形に落とした。

| # | 仮説 | 作った特徴 |
|---|---|---|
| 1 | 教育予算のオーナー（買い手）が組織に居るか | 組織図に人事/人材開発/教育/研修部門があるか、部署数 |
| 2 | 研修対象人口（現場労働者を除いた知識労働者数） | 現場拠点比率、推定知識労働者数、1拠点あたり従業員 |
| 3 | 席課金なので総額でなく一人あたり支払い能力 | 営業利益/従業員、売上/従業員、営業CF/従業員、ソフト投資/従業員 |
| 4 | ツール先行・人材後追いギャップ（道具は買ったが使えていない） | ソフト投資 × (6-Q8) を3通り、ソフト投資 × ツール不満 |
| 5 | 技術は入ったが人が追いついていない | Q3-Q8、Q5-Q8、Q1-Q8、Q11-Q3、Q1×(6-Q8) |
| 6 | 資本集約 vs 人材集約 | 減価償却費/総資産、減価償却費/従業員、有形投資/ソフト投資 |
| 7 | E7の不満スコアにQ8を足す | 不満5 = 不満4 + (6-Q8) |

仮説7の背景: `exp/cross_features.py` の不満スコアは Q7/Q10/Q2/Q4 の4問で、
**Q8は「全体での単変量順位が5位以下」という理由で除外されている**。
帯で唯一有意なのがQ8なので、選抜基準そのものが帯を見ていない可能性を疑った。

### 4.2 結果

25本中、95%CIで有意になったのは6本。**すべてQ8を含む。**

|---|---:|---|---|---|
| 不満5(Q7,10,2,4,8) | 0.607 | [0.530, 0.680] | YES | no |
| ソフト投資売上比 × 成果未実感 | 0.594 | [0.519, 0.668] | YES | no |
| log_ソフト投資 × 成果未実感 | 0.590 | [0.515, 0.660] | YES | no |
| 不満_Q8のみ | 0.584 | [0.513, 0.655] | YES | no |
| Q3導入 - Q8成果 | 0.582 | [0.505, 0.657] | YES | no |
| Q5セキュリティ - Q8成果 | 0.581 | [0.509, 0.655] | YES | no |
| 推定知識労働者数_log | 0.575 | [0.501, 0.649] | YES | no |
| （参考）不満4(E7現行) | 0.576 | [0.491, 0.655] | no | no |

**きれいに死んだ仮説**（ここが重要な情報）:

| 特徴 | 帯内AUC | 読み |
|---|---:|---|
| 組織図_人事系部門あり | 0.481 | **買い手の存在は無関係。** ほぼ全社が人事部を持つ |

「予算オーナーが居るか」「一人あたり払えるか」「研修対象が何人か」という、
B2B購買で最も自然な3つの物語が、いずれもこのデータでは無情報だった。

### 4.3 決定的テスト — 現本命の上に足すと動くか

単変量で有意でも、合成に効かなければ意味がない（exp020/023/025 と同型の罠）。
帯228行の中だけで、現本命スコアのlogitに1列足して5seed CVした。

| 追加特徴 | 帯内AUC | 帯内AP |
|---|---|---|
| 現本命スコアのみ | 0.8110 | 0.7458 |
| + 不満5 | 0.8152 (+0.0042, 4/5) | **0.7390 (-0.0068, 1/5)** |
| + 不満_Q8のみ | 0.8149 (+0.0039, 4/5) | **0.7419 (-0.0039, 1/5)** |
| + log_ソフト投資 × 成果未実感 | 0.8127 (+0.0017, 3/5) | 0.7452 (-0.0006, 3/5) |
| + Q3導入 - Q8成果 | 0.8122 (+0.0012, 4/5) | 0.7425 (-0.0033, 2/5) |
| + ソフト投資売上比 × 成果未実感 | 0.8112 (+0.0001, 3/5) | 0.7451 (-0.0007, 2/5) |

**全候補でAPが下がる。判定はREJECT。**

特に重要な2点。

1. **「研修/教育」への言及は全社の97〜98%に現れる。** 生成テンプレートの一部であり、

「テキストからもっと情報を取る」という方向は、取りたい情報を名指ししても取れない。

## 5. なぜドメイン知識が特徴量に変換できなかったか

理由は単純で、**E0_anchor（LightGBM 71列）がアンケート11問と財務42列を既に全部
生で持っている**からである。上で作った25本はすべて既存列の変換であり、
木は分割の組み合わせでそれを近似できる。

これは experiments.md の既知の教訓そのままである。

> baseline（生の財務額＋LGBMネイティブカテゴリ）は既に強い。木が分割で近似できる変換
> （比率・正規化・target encoding）は上乗せしにくい。

Q8がE7の不満スコアに入っていないのは事実だが、それは**E7という1本のExpertの
手作り軸に無い**だけで、**モデル全体としてはE0経由で持っている**。
帯内スクリーニングで有意に見えたのは、E0が既に使っている情報を単変量で再発見しただけ。

**ドメイン知識が効くとしたら、42列の外から情報を持ち込む形でなければならない。**
42列の内側での組み替えは、E0がやり終えている。

そして §4.5 のとおり、42列の外にある唯一の情報源＝テキストも、
取りたい情報を名指ししたキーワード15系統すべてで帯内AUCが有意にならなかった。

残る唯一の隙間は、**「言及の有無」ではなく「言い方の質」** である。
「DX教育に投資する」と書いた企業の購入率は0.440、書かなかった企業は0.431で差が無いが、
「予算枠と時期を伴う具体的計画」と「所信表明レベルの定型文」の区別は
キーワードでは測れない。ここだけはLLMに読ませる価値が残る。
ただし §4.5 の結果を踏まえると事前確率は低い。

## 6. プレゼン審査への転用

モデリング上は空振りだったが、営業側の示唆としては強い。

1. **742社のうち約7割は、機械的にほぼ確実に判定できる。**
   小型市場・BtoC・小売/生活用品は買わない。ソフト投資が突出した大手IT/自動車は買う。
2. **営業判断が本当に要るのは残り3割＝中規模BtoBのDX関連企業。**
   規模も投資額もアンケート回答も全部「真ん中」の層である。
3. **その層で唯一効く軸は「DXの成果をまだ実感できていない」こと。**
   技術は入れた（Q3高）が成果が出ていない（Q8低）企業、
   セキュリティは整えた（Q5高）が成果が出ていない企業ほど買う。
4. 逆に、**「人事部があるか」「一人あたり利益がいくらか」「現場比率」では全く切れない。**
   直感的なターゲティング軸が効かないことを、数字で示せる。

拡販施策としては「DXツールを導入済みだが成果実感が低い中規模BtoB企業」を
優先リストにする、という提案に直結する。
